Prefix Sum Pattern — Cheat Sheet

Reference · Interview Patterns Track · Go

Lesson 1: Subarray Sum Detection Glossary

1. Build the Prefix Sum Array

pre[0] = 0
pre[i] = pre[i-1] + a[i-1]   for i = 1..len(a)

// Go
func BuildPrefixSum(a []int) []int {
    pre := []int{0}
    for i := range a {
        pre = append(pre, pre[i]+a[i])
    }
    return pre  // len(pre) == len(a)+1
}

pre[i] = sum of the first i elements of a.

Example: BuildPrefixSum([1, 2, 3, 4]) → [0, 1, 3, 6, 10]

2. O(1) Range Sum Query

sum(a[i..j]) = pre[j+1] - pre[i]

// Go
func RangeSum(pre []int, i, j int) int {
    return pre[j+1] - pre[i]
}

Example: RangeSum([0,1,3,6,10], 1, 3) → 9 (i.e. 2+3+4)

3. Subarray Sum Detection — O(n)

Question: Does any contiguous subarray sum to target?

func HasSubarraySum(a []int, target int) bool {
    seen := map[int]bool{0: true}
    running := 0
    for _, v := range a {
        running += v
        if seen[running - target] {
            return true
        }
        seen[running] = true
    }
    return false
}

Why it works: pre[j+1] - pre[i] = target → pre[i] = pre[j+1] - target. At each step, check if running - target was seen earlier. {0: true} handles subarrays starting at index 0.

4. Subarray Sum Counting — O(n)

Question: How many contiguous subarrays sum to target?

This is LeetCode 560.

func CountSubarraysWithSum(a []int, target int) int {
    counts := map[int]int{0: 1}
    running, total := 0, 0
    for _, v := range a {
        running += v
        total += counts[running - target]
        counts[running]++
    }
    return total
}

Change from detection: seen-set (map[int]bool) becomes seen-map (map[int]int), tracking how many times each prefix sum appeared. Each earlier occurrence is a distinct valid subarray, so you add counts[running - target] to the total. {0: 1} handles subarrays starting at index 0.

Key Gotchas

  • Initialize with zero. {0: true} or {0: 1}. Without it, subarrays starting at index 0 are missed.
  • Check before adding. The current running is added to the set/map after checking running - target, so you're only matching prefix sums from earlier positions.
  • Go map zero-value. counts[running - target] returns 0 if the key doesn't exist — no need for an existence check.
  • Negative numbers are fine. This approach works with any integers. Sliding window does not work with negatives.

Complexity

Operation Time Space
Build prefix array O(n) O(n)
Range sum query O(1) O(1) (or O(n) for stored array)
HasSubarraySum O(n) O(n)
CountSubarraysWithSum O(n) O(n)
